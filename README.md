# Tracking California — website redesign prototype

A static, hi-fidelity design prototype for the new trackingcalifornia.org. It exists to
make the redesign concrete: real brand, real layout, clickable navigation.

**This is not the live site.** Content is illustrative placeholder copy. The live site
remains at <https://trackingcalifornia.org>.

Live preview: <https://jo-wilkin-tc.github.io/tc-website-redesign/>

## Viewing locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

Plain HTML and CSS — no framework and no build step. Shared assets are in `assets/`:
`styles.css` and `meganav.css` (the design system and the navigation), `main.js` and
`meganav.js`, the logo and imagery.
